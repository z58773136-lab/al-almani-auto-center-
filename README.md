# مركز الألماني المتكامل للسيارات

موقع عربي لمركز صيانة السيارات، بواجهة متجاوبة تدعم العربية واتجاه الكتابة من اليمين إلى اليسار.

## محتويات الموقع

- تعريف بخدمات الصيانة والسمكرة والرش والتلميع وقطع الغيار والفحص.
- نموذج طلب حجز مع بيانات المالك والسيارة.
- رقم مرجعي للطلب وخانة استعلام.
- روابط واتساب والعنوان على خرائط Google وساعات العمل.

## المعاينة والنشر

الصفحة الرئيسية هي `index.html`. يمكن نشرها من إعدادات GitHub Pages باستخدام الفرع `main` ومجلد الجذر `/`.

## إعداد خدمة الحجوزات الخلفية

مجلد `supabase/` يحتوي على مخطط قاعدة البيانات ووظيفة خلفية لتسجيل الحجوزات والاستعلام عنها. قاعدة البيانات تمنع القراءة والكتابة العامة؛ الاستعلام يتطلب الرقم المرجعي ورقم الجوال المسجل. مفتاح الخدمة السري يبقى داخل Supabase ولا يوضع في ملفات الموقع.

الحجوزات والاستعلام متصلان بمشروع Supabase عبر الوظيفة الخلفية `bookings`. الاستعلام يتطلب الرقم المرجعي ورقم الجوال المسجل. مخطط قاعدة البيانات في `supabase/migrations/20261021000100_booking_requests.sql`، ومصدر الوظيفة في `supabase/functions/bookings/`. مفتاح الواجهة المنشور هو مفتاح عام مخصص للمتصفح؛ لا يحتوي المستودع على مفتاح خدمة سري.
