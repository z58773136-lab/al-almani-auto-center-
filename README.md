# مركز الألماني المتكامل للسيارات

موقع عربي لمركز صيانة السيارات، بواجهة متجاوبة تدعم العربية واتجاه الكتابة من اليمين إلى اليسار.

## محتويات الموقع

- تعريف بخدمات الصيانة والسمكرة والرش والتلميع وقطع الغيار والفحص.
- نموذج طلب حجز مع بيانات المالك والسيارة.
- رقم مرجعي للطلب وخانة استعلام.
- روابط واتساب والعنوان على خرائط Google وساعات العمل.

## المعاينة والنشر

الصفحة الرئيسية هي `index.html`. يمكن نشرها من إعدادات GitHub Pages باستخدام الفرع `main` ومجلد الجذر `/`.

> نموذج الحجز الحالي يعمل داخل المتصفح ويخزن الطلبات محليًا؛ يلزم ربطه بخادم أو خدمة نماذج حتى يستقبل المركز طلبات الزبائن ويستعلم عنها مركزيًا.
